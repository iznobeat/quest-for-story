# Character artwork

Selected asset: `characters.png`. Generated with the built-in image-generation tool.

The transparent master supplies the six detailed character designs. `characters.js` registers the observed row boundaries and head anchors, assembles standing lower bodies with the expressive upper-body poses, and animates complete-frame walking, breathing and speech. The background atlas is unchanged.

The subsequent `characters-v2.png` is an unused revision: its checkerboard is opaque, so it is deliberately not loaded by the game.

## Original prompt

Use case: stylized-concept. Asset type: production transparent pixel-art character animation atlas for an original 1990s point-and-click adventure. Create ONE image with an EXACT uniform SIX COLUMN by FOUR ROW grid, 24 cells, no lines or labels. Landscape image 1536x1024, cells 256x256. Each cell contains exactly one full-body sprite centered horizontally, same ground baseline at 240px in each cell, full body about 215px tall and 110px wide, ample transparent margin, absolutely no overlap across cells. GENUINELY TRANSPARENT background, no scenery, no ground, no shadows outside the characters, no checkerboard drawn into image. Gorgeous detailed VGA pixel art, expressive caricature faces, shaped silhouettes, realistic adult proportions with slightly enlarged expressive heads, rich 1990s hand-pixelled shading, visible pixel clusters, black-brown outline, fabric folds and highlights, warm skin shading, no blocky Minecraft bodies. Original whimsical adventure characters, 3/4 view facing viewer-right.
